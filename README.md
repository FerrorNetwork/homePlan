# ДомПроект

Русскоязычное веб-приложение, которое ведёт владельца жилья по шести шагам: **планировка → инженерия → стиль → дизайн (варианты, правка, плитка, 3D, рендеры) → список покупок → смета по городу**. Следующий шаг открывается после сохранения предыдущего, к любому можно вернуться. Инженерию можно пропустить — тогда смета без инженерных работ и с предупреждением.

Без сборки и npm-зависимостей: сервер — чистый Node.js 20+, клиент — ES-модули. Three.js, SheetJS и pdf.js подгружаются с CDN по требованию (3D, Excel, импорт PDF-чертежа).

## Запуск

```powershell
Copy-Item .env.example .env   # по желанию: ключи Gemini / OpenAI
node server.mjs               # или .\start.ps1
```

Откройте <http://localhost:4173>. Порт меняется переменной `PORT` в `.env`.

Без сервера (например, через любой статический хостинг) приложение работает в «локальном режиме»: всё хранится в браузере, ИИ — встроенный подборщик, вход и ссылки для чтения недоступны.

## Что умеет

**Главная для гостей.** Неавторизованный посетитель видит промо-страницу: заголовок со сменяющимися словами, анимированный план квартиры (стены рисуются, затем появляются комнаты, мебель, розетки и кабели), счётчики, шаги, примеры ГОСТ-листа и стилей, частые вопросы. Анимации отключаются при системной настройке «уменьшить движение». Вошедший пользователь сразу попадает в свои проекты (`#/projects`).

**Планировка (раздел 3.1 ТЗ).** Стены по точкам с привязкой к сетке, концам и углам 45°, ввод длины и угла; типы стен (несущая / перегородка / мокрая зона) с толщиной; статус «новая / под снос» попадает в смету; предупреждение при удалении, переносе и проёмах в несущей стене. Комнаты прямоугольником (со стенами) или по контуру, назначение и высота потолка, площадь/периметр/объём/площадь стен без проёмов. Двери, окна, арки, балконные блоки из библиотеки. Этажи, лестницы, колонны, ниши, скосы мансарды. Подложка JPG/PNG/PDF с масштабом по известному размеру и распознаванием стен (локально или через ИИ) — пользователь принимает или удаляет предложения. Отмена/повтор 100 шагов, автосохранение, именованные версии. Экспорт PDF, PNG, SVG, DXF; импорт DXF. Виды: 2D, 3D-обзор, прогулка от первого лица (WASD).

**Инженерия (3.2–3.4).** Розетки, выключатели, светильники, щиток, коробки с высотой монтажа; приборы водоснабжения и канализации, стояк, коллектор; радиаторы, котёл, контуры тёплого пола; вентканалы и вытяжки. Ортогональные трассы с длиной, прокладка по стене/потолку/в полу, уклон канализации. Группы с автоматом, кабелем и УЗО, расчёт нагрузки и тока. Настраиваемый набор проверок (расстояния от воды и плиты, точек на группу, перегрузка, сечение кабеля, уклон и длина отвода, пересечения трасс, несущие стены, вентиляция мокрых зон) — предупреждения, а не блокировка. Ведомость точек и длин, слои видимости, автоматическая разводка кабелей по группам в обход несущих стен.

**Чертежи по ГОСТ.** Переключатель «Схема / Чертёж ГОСТ» на шаге «Инженерия» показывает план в чертёжном оформлении:
- условные обозначения электрооборудования по ГОСТ 21.210-2014, санитарно-технических приборов — по ГОСТ 21.205-2016, отопления — по ГОСТ 21.206-2012;
- трубопроводы с буквенными кодами В1, Т3, К1, Т1 и диаметрами, уклон канализации со стрелкой;
- номера групп и марка кабеля на линиях;
- несущие стены со штриховкой, размерные цепи с засечками (ГОСТ 2.307), номера и площади помещений.

«Комплект листов ГОСТ (PDF, A3)» печатает листы с рамкой и основной надписью по форме 3 ГОСТ Р 21.101-2020:
- план электрооборудования (ЭОМ) с условными обозначениями, таблицей групп и примечаниями;
- однолинейную схему щита (обозначения аппаратов по ГОСТ 2.755);
- план водопровода и канализации (ВК), план отопления (ОВ);
- спецификацию оборудования, изделий и материалов по ГОСТ 21.110.

Листы помечены как эскизная документация.

**Стиль и ИИ-дизайн (раздел 4).** 12 готовых стилей с палитрой, материалами и правилами; свободное описание; 1–20 референсов (JPG/PNG/WebP до 10 МБ) с разбором «как система поняла» до генерации; бюджет, жильцы, дети, животные, обязательные и запрещённые предметы; выбор комнат и приоритеты; отключение декора. Генерация 3 вариантов (сбалансированный, экономичный, акцентный) с зонированием, отделкой, сценариями света по точкам электрики и объяснением. **ИИ выбирает только ID из каталога**, сервер отбрасывает всё, чего в каталоге нет; расстановку всегда делают детерминированные правила эргономики (проходы, двери, окна, розетки, радиаторы, стояки). Если места или товара нет — зона остаётся пустой с пояснением. Сравнение вариантов рядом, ручная правка (перетаскивание, поворот R, удаление, «похожие»), пересборка одной комнаты, чат («замени диван на угловой», «сделай светлее/дешевле», «убери декор») с показом отличий. Рендеры: ИИ-изображение через провайдера или 3D-превью сцены.

**Каталог и покупки (раздел 5).** Карточки с ID, брендом, артикулом, размерами, ценами по магазинам с датой, доставкой по городу и наличием. Перед показом проверяется: размеры, цена не старше 7 дней, доставка, наличие, ссылка (серверная проверка доступности). Список по комнатам/категориям/магазинам, «где дешевле купить комплект», аналоги по размеру/стилю/цене с мгновенным пересчётом сметы, «сообщить об ошибке», импорт фидов YML/XML, CSV, JSON, витрины магазинов города. Экспорт в Excel (с формулами) и PDF, ссылка только для чтения.

**Плитка (раздел 6).** Поверхность кликом: пол, стена целиком, участок по высоте, фартук над кухней. Прямая, 1/2, 1/3, диагональ, ёлочка, шестигранник; шов, старт (угол, центр, дверь, видимая сторона), зазор, ручной сдвиг сетки перетаскиванием. Проёмы, розетки, трубы, ванна и встроенная мебель вычитаются. Предупреждения об узкой подрезке, шве на розетке, несимметрии. Автоподбор 3 раскладок (меньше отходов / симметрично / минимум подрезки). Целые и подрезанные, повторное использование обрезков, запас 10/15%, упаковки, клей и затирка по формулам, нумерованные ряды и ведомость подрезок в PDF, декор-вставки кликом. Плитка показывается в 3D и сама попадает в смету.

**Смета (раздел 7).** Тип объекта и состояние сдачи (в параметрах проекта или прямо в смете):
- **вторичка** — демонтаж старой отделки, черновые и чистовые работы, вывоз мусора;
- **новостройка без отделки** — без демонтажа, остальное с нуля;
- **черновая отделка от застройщика** — не считаются стяжка, штукатурка стен, разводка кабелей, щиток и трубы; розетки ставятся в готовые подрозетники;
- **предчистовая (white box)** — дополнительно не считаются шпаклёвка, выравнивание потолка и гидроизоляция; стены и потолки только красятся.

Радиаторы в новостройке считаются установленными застройщиком. В смете перечислено, что исключено. Девять разделов из ТЗ: от демонтажа до накладных. Объёмы из модели, товары из списка покупок, работы — по справочнику расценок с версией и датой; коэффициенты 21 города, уровни «эконом / стандарт / премиум» с итогом по каждому, резерв. Ручная правка цены, количества и исполнителя сохраняется при пересчёте; свои позиции. Вид по разделам и по комнатам, итоги «материалы / мебель / работы / всего», источник и дата каждой цены, точность ±10–15%. Сравнение двух вариантов дизайна и журнал «что подорожало». PDF, Excel с формулами, ссылка для бригады с комментариями.

**Аккаунты (9.2).** Гость строит планировку на устройстве; для ИИ, сметы, сохранения на сервере и ссылок нужна регистрация (согласие на обработку ПД). Пароли — scrypt, сессия — HttpOnly-cookie. Выгрузка своих данных и удаление аккаунта со всеми файлами.

## Реальные товары: фиды магазинов

Стартовый каталог — демонстрационный: магазины «ДомМаркет», «СтройБаза», «Интерьер Плюс» условные, цены примерные, а ссылка ведёт на поиск похожего товара на Яндекс Маркете. Реальные товары со страницами в магазинах, фото, ценами и наличием подключаются фидами:

1. Получите у магазина выгрузку каталога: YML/XML (формат Яндекс Маркета), CSV или JSON — ссылку на файл или сам файл. Её дают по договору, в партнёрской программе или в кабинете поставщика.
2. Войдите администратором каталога: это адреса из `ADMIN_EMAILS` в `.env`, а если переменная пустая — первый зарегистрированный пользователь.
3. На шаге «Покупки» откройте вкладку «Каталог и фиды» → «Подключить фид по ссылке» или «Загрузить выгрузку файлом». Укажите города доставки и срок.

Что делает сервер:
- забирает фиды по ссылкам раз в `FEED_REFRESH_HOURS` часов (по умолчанию 24); поддерживаются `.gz` и кодировка windows-1251;
- разбирает категории, размеры (параметры «Ширина/Глубина/Высота» в мм, см или м, тег `<dimensions>`, размер в названии), цвет, материал, фото, наличие, упаковку плитки и ламината;
- объединяет один товар из разных магазинов по бренду и артикулу в одну карточку с несколькими ценами;
- отдаёт общий каталог всем проектам и обновляет цены при каждом открытии сметы;
- товары без размеров видны в каталоге, но в расстановку не попадают.

Чтобы ИИ подбирал только реальные товары, снимите в проекте флажок «Использовать демо-каталог». Если подходящего товара в фидах нет, зона останется пустой с пояснением.

Минимальный CSV: `Артикул;Название;Цена;Ссылка;Бренд;Ширина, см;Глубина, см;Высота, см;Категория`.

Готового коннектора к API Леманы ПРО нет: его открытая документация описывает только API маркетплейса для продавцов, а доступ выдаётся после одобрения заявки. Когда магазин даст доступ к API или YML-выгрузку, её можно подключить здесь же.

## ИИ-провайдеры

Ключи задаются только в `.env` на сервере и никогда не попадают в браузер:

| Переменная | Назначение |
|---|---|
| `GEMINI_API_KEY`, `GEMINI_MODEL`, `GEMINI_IMAGE_MODEL` | подбор, разбор референсов, чат, распознавание плана; рендеры |
| `OPENAI_API_KEY`, `OPENAI_MODEL`, `OPENAI_IMAGE_MODEL` | то же через OpenAI Responses API и генерацию изображений |

Без ключей работает встроенный подборщик, локальный разбор цветов референсов, локальное распознавание стен и 3D-превью вместо фотореалистичных рендеров. Провайдер выбирается на шаге «Стиль».

## Телефон и планшет

- Компактная шапка в две строки, шаги прокручиваются.
- Над планом — кнопки-иконки; масштаб щипком, сдвиг двумя пальцами.
- В 3D «от первого лица» — экранные кнопки ходьбы и поворота.
- Списки покупок и сметы показываются карточками, диалоги открываются нижним листом.
- На телефоне удобно смотреть проект, покупки и смету; полноценно рисовать план — на планшете или компьютере.

## Структура

```
index.html, css/app.css      оболочка и дизайн-система (светлая и тёмная темы)
js/main.js                   маршрутизация по шагам, меню, вход, горячие клавиши
js/store.js                  состояние, история 100 шагов, автосохранение, версии
js/data/                     каталог (демо), стили, города, справочник расценок
js/core/                     геометрия, модель, правила, плитка, смета, подбор и расстановка, экспорт
js/views/                    экраны: промо-главная, план, инженерия, стиль, дизайн, плитка, покупки, смета, ссылка
js/views/gostplan.js         план в чертёжном оформлении ГОСТ и спецификация
js/views/gostsheets.js       листы A3 с рамкой и основной надписью
server.mjs                   API: аккаунты, проекты, версии, загрузки, ссылки, проверка ссылок, каталог, ИИ
lib/feed-sync.mjs            загрузка и ежедневное обновление фидов магазинов
js/core/feeds.js             разбор YML/CSV/JSON (общий для сервера и браузера)
legacy/                      файлы первой версии MVP (для справки)
```

Данные сервера лежат в `data/` (в `.gitignore`).

## Ограничения текущей версии

- Стартовый каталог демонстрационный, помечен «демо». Реальные товары появляются после подключения фидов магазинов (см. раздел выше и [store-research.md](./store-research.md)).
- Справочник расценок — демо-версия; для продакшена нужна проверенная региональная база с ежеквартальным обновлением.
- Хранение — файлы на сервере. Для 100 000 проектов и требований 152-ФЗ нужны PostgreSQL, объектное хранилище в РФ, резервные копии, HTTPS и очередь задач ИИ (раздел 8 ТЗ).
- Проверки норм — подсказки по мотивам ПУЭ и СП, не замена проекту. Смета — оценка, а не оферта.
- 3D-модели мебели упрощённые, построены по размерам карточки.
