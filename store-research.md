# Магазины и источники каталога

Проверено 1 ноября 2026 г. для подготовки каталожного этапа. Под «источником» здесь понимается либо программный фид/API, либо обычная ссылка на витрину для покупателя. Эти варианты в приложении разделены.

## Решение по каждому магазину

| Источник | Что найдено | Реализация в приложении |
|---|---|---|
| Лемана ПРО | Официальная документация содержит B2B API каталога и региональных цен; доступ требует регистрации интеграции, а для цены нужен ID региона. См. [API каталога и цен](https://developers.lemanapro.ru/api_b2b/) и [порядок подключения партнёра](https://developers.lemanapro.ru/partners-started/). | Ссылка на региональную витрину и API-документацию. Автоматические цены включаются после получения доступа и таблицы `regionId`. |
| Стройландия | Официальные страницы описывают портал поставщика и сотрудничество, но в открытом поиске не обнаружен публичный фид/API для независимой потребительской витрины. См. [раздел поставщикам](https://stroylandiya.ru/postavshikam/). | Ссылка на магазин; внешний фид — запросить у сети. Городскую доступность проверять в каталоге магазина. |
| Авито | Официальный [каталог API](https://developers.avito.ru/api-catalog) доступен как инструментарий для интеграций. В публично обнаруженных материалах нет общего API-каталога чужих объявлений с ценами и наличием, пригодного для нашей сметы. Это вывод по доступной документации; поэтому приложение не делает парсинг и не импортирует объявления автоматически. | Городская ссылка на поиск. Объявления можно открывать и самостоятельно добавлять как пользовательские позиции после проверки цены, продавца и габаритов. |
| Максидом | Есть действующий [интернет-каталог](https://www.maxidom.ru/catalog/) с товарами для плитки, отделки, мебели и стройматериалов; сайт указывает регионы и доставку. | Добавлен как городская витрина/кандидат на запрос фида. Программное подключение пока не подтверждено. |

## Местные поставщики

Для текущего города Самара добавлены:

- [Строй-С](https://samara.stroy-s.org/catalog/stroitelnye-materialy/) — региональная витрина с каталогом стройматериалов, интерьерных товаров и доставкой по Самаре.
- [Тёплый Дом](https://bazatd.ru/catalog/) — местный интернет-каталог строительных и отделочных материалов.
- [Максидом](https://www.maxidom.ru/) — сеть с Самарой среди своих регионов.
- [Лемана ПРО · Самара](https://samara.lemanapro.ru/) — региональная витрина сети.

Для других городов в приложении заведены первичные местные каталоги: Мегастрой (Казань), Петрович и ВИМОС (Санкт-Петербург), Петрович и Уррес (Екатеринбург), Диола и рынок на Доватора (Новосибирск). По остальным городам пока показаны федеральные сети, доступность доставки и локальные фиды требуют отдельной проверки.

Примеры каталогов: [Мегастрой](https://megastroy.com/), [Петрович · Екатеринбург](https://ekaterinburg.petrovich.ru/catalog/), [Уррес](https://urres.ru/), [Диола](https://www.diola.ru/), [рынок на Доватора](https://www.nsk-rinok.ru/), [ВИМОС](https://vimos.ru/).

## Что добавлено в приложение

- Список розничных витрин меняется вместе с городом проекта.
- Для каталогов без подтверждённого API/фида есть импорт YML/XML, CSV и JSON.
- Импорт связывает товар с URL и источником, заменяет запись при повторном URL и записывает дату импорта.
- ИИ получает только позиции с размерами, ссылкой и не демо-меткой. Если из каталога нет подходящего товара, модель не может дописать выдуманную позицию в список.
- Для Авито показана ссылка на поиск, а объявления отделены от подтверждённых товаров магазинов.

## Следующая интеграционная работа

Для регулярной загрузки цен и остатков нужны согласованные фиды/API магазинов. Первый практический коннектор — Лемана ПРО B2B: запросить доступ, сопоставить региональные ID, проверить поля карточки товара и затем включить периодическое обновление. Для Стройландии и местных магазинов — запросить согласованный YML/XML/CSV и частоту обновления. До получения этих источников приложение импортирует предоставленные файлы вручную; оно не показывает демо-цены как подтверждённые.
